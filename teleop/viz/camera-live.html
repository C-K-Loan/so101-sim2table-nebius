🎥 SO-101 Live Cam Preview

OFF Camera stream stops the second you close this tab. No background use.
Permission flow: first time you click Start, your browser asks for camera access. Allow it. Camera list only shows after you've granted permission once (browser privacy). Need HTTPS or localhost or Tailscale IP (which this is) for getUserMedia to work.
Click Start to grant permission + see live feed.

💡 Tips

  • If you only see one camera, click Start once, allow permission, then click 🔄 - labels appear only after permission.
  • Look for IW-2000-1 or similar USB cam name - that's the hackathon station cam.
  • Snapshot button saves a PNG to your Downloads folder.
  • Closing the tab releases the camera. No background streaming.
  • If the station rig uses the cam via lerobot-record, close this tab FIRST - only one process can own a cam.
